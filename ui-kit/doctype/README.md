# ui-kit/doctype

Renders a Frappe v16 DocType JSON into a standalone desk form page (desk-form.html shell).

    node render-doctype.mjs <doctype.json> [--doc sample.json] [--meta-dir dir]... [--custom custom_fields.json] [--locale en-IN] [--tab n] [--out file.html]

- `lib/layout.mjs` buildLayout: field_order, implicit Details tab / unlabelled section, Tab/Section/Column/Fold breaks, hidden pruning, collapsible logic.
- `lib/control.mjs` esc, wrapControl, formatValue.
- `fields/*.mjs` default export `{ Fieldtype: (df, ctx) => html }`; all files merged, duplicates warn; unknown types render a read-only fallback.
- `lib/customize.mjs` applyCustomizations (custom fields with insert_after chains, property setters); `lib/depends.mjs` evalDepends (safe parser, null when unsupported; `node lib/depends.test.mjs`).
- `Data` fields with `options` (Email, URL, Phone, Name, Barcode) resolve to the `Data:<option>` renderer.
- Fixtures: `fixtures/<app>/<doctype_snake>.json`; child doctypes resolved from the input dir, `--meta-dir`, and fixtures.
- Test: `node render-doctype.mjs fixtures/test/layout_test.json` prints tab/section/column/field counts (3/6/11/12).

## Batch
- `./render-all.sh` renders every fixture into `out/<name>.html` (sales_invoice also per tab: `sales_invoice_tab0..5.html`).
- `./shot-all.sh` screenshots each `out/*.html` to `out/*.png` at 1440x900 via `shot-doctype.mjs` (file://, no bench login).
- `node coverage.mjs` writes `out/coverage.json` (fieldtype -> renderer file or "fallback").

## Known gaps
- Client scripts (`*.js` form scripts), runtime-added buttons, custom indicators and `frm.set_query` filters are not represented.
- `depends_on`, `mandatory_depends_on`, `read_only_depends_on` are applied in layout (false hides; true sets reqd/read_only); expressions evalDepends cannot evaluate keep the field, marked `dep-unknown` (dashed outline).
- Child doctype JSON for the sample doctypes is in fixtures/erpnext; child tables for other doctypes without fixtures still show only the "No." header.
- `--custom` accepts `[...]`, `{custom_fields: [...]}` or a doctype->fields map (`fixtures/india_compliance/custom_fields.json`, generated by `tools/convert-custom-fields.mjs`; placeholder option lists for state/port codes).
- `shot-doctype.mjs --full` captures the whole form (cap 16000px).
- Markup follows v16 controls (read from frappe version-16 JS, not scss; not compared against a live bench). Barcode is a display pattern, not scannable.
- Sidebar, navbar and breadcrumbs come from `pages/desk-form.html`.
- `live/` holds captures of blank new forms from a local bench (screenshots, field boxes, control markup). They show bench-specific custom fields, app names and workspace sidebars, so the folder is gitignored. Recapture with `live/_cap.mjs` (needs a bench).
- Pixel parity: `python3 tools/pixdiff.py` compares `out/<dt>.png` with `live/<dt>.live.png` (live downscaled 2x; a pixel counts as different when its grey difference is above 24/255). Current, first viewport: sales_invoice 4.3%, customer 1.9%, item 3.9%, company 1.4%. Sales Invoice is rendered from a sample document, the live capture is a new form, so that figure includes data differences. Zero is not reachable: fonts, dock icons and bench-specific custom fields differ.
- GST Settings has no live capture (India Compliance is not installed on the bench), so its markup is unverified.
- Saved-document forms (`--doc` with a name) keep the shell's main + form-sidebar layout (main column 881px); new forms use the live 900px centred column with no form sidebar. `out/customer_saved.html` is the saved variant.
- The dock rail highlights the Selling icon for workspaces that have no rail icon (GST India).
- Small Text height (80px) is unconfirmed against Frappe scss.
