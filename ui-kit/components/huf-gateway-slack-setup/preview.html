Slack setup

1. Create the Slack app

Copy the app manifest, then create a Slack app from it. It sets up the permissions and the events address for you.

Create app from manifest

2. Add your keys

Install the app to your workspace, then open the Credentials tab and paste the Bot User OAuth Token (starts with xoxb-) and the Signing Secret. Then, in Slack, click Save Request URL under Event Subscriptions.

3. Check the connection

  • Bot token added

    A bot token is saved.

  • Token is a bot token

    This is a bot token (starts with xoxb-).

  • Slack accepts the token

    Connected to Northwind Trading.

  • Required permissions granted

    All required permissions are granted.

  • Signing secret added

    A signing secret is saved.

  • Slack confirmed the Request URL

    Slack has confirmed the events address.

  • People can connect their own account

    Direct messages are not open, so people who have not been approved cannot reach the connect prompt.

    Set the access policy to Open so people can connect their own account, or add each person to the access list first.

  • Shared channels (Slack Connect)

    Channels shared with other organizations are not supported. Huf works in channels and DMs inside your own workspace.

4. Send a test message

Huf will send a direct message to one person. Enter their Slack member ID or their email.
