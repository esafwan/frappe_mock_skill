# pos-bill-split-dialog

Split bill dialog (BillSplitDialog.tsx): checklist of the invoice lines with 12px check boxes, per-line quantity mover for lines with qty above one, the Customer for new bill box (same-as-original checkbox or a customer picker), a stays / moves totals strip and the Split bill button.

Shown from the order actions menu when a bill should be split into two.

Source: pos/src/components (URY v16 @100c43fe2e). Styles: tokens/css/ury-v16/components/pos-dialogs.css. Variants: see states.json.
