The address you open Huf at in your browser, for example https://huf.example.com. https:// is added if you leave it out (http:// for localhost and .local addresses), and anything after the host name is dropped.

Use the email and password you sign in to Huf with.

Where do I find these?
  1. Open your Huf site in a browser and go to My Settings (your avatar menu).
  2. In the API Access section, choose Generate Keys.
  3. Copy the API key and the API secret here. The secret is shown only once.
