# pos-table-transfer-dialog

Table action dialogs of the dine-in floor, one component with four kinds: transfer (TablePickerDialog: current table, search, vacant tables grouped by room), merge (MultiSelectTableDialog: two-column table checklist with selected-count badge, merging and done phases), unmerge (ConfirmDialog with a danger button) and captain-transfer (UserPickerDialog: current captain, search, captain list).

Shown from the table actions menu (Transfer table, Merge tables, Unmerge tables, Transfer captain).

Source: pos/src/components (URY v16 @100c43fe2e). Styles: tokens/css/ury-v16/components/pos-dialogs.css. Variants: see states.json.
