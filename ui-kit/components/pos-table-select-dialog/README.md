# pos-table-select-dialog

Select Table dialog (TableSelectionDialog.tsx): 672px wide (max-w-2xl), 5/6 of the viewport high, header with close button, room tabs (tab buttons, selected room in primary-50) and a three-column grid of table chips with shape icon, occupied / reserved badges and merged-group label. The source has no search field, so none is drawn.

Shown when a server starts a dine-in order and has to pick the table.

Source: pos/src/components (URY v16 @100c43fe2e). Styles: tokens/css/ury-v16/components/pos-dialogs.css. Variants: see states.json.
