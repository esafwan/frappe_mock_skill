Knowledge projection

Optionally promote high-confidence memories into a permanent Knowledge Source.

Automatically copies memory records that meet or exceed both Min Confidence and Min Importance below into a Knowledge Source, making them retrievable outside the memory system.

Required when Auto Promote is enabled. The Knowledge Source that promoted memories are written into.

Minimum confidence score (0-1) a memory record must have to be promoted. A record is promoted only when it meets or exceeds both this and Min Importance.

Minimum importance score (0-1) a memory record must have to be promoted. A record is promoted only when it meets or exceeds both this and Min Confidence.
