# pos-bill-merge-dialog

Merge bill dialog (BillMergeDialog.tsx): 672px dialog capped at 85vh with a search field, a scrolling list of open bills (name, customer and table, amount) and a Load more button. The combined total is not part of this dialog; it appears on the merged bill panel after merging.

Shown from the order actions menu when another open bill should be merged into the current one.

Source: pos/src/components (URY v16 @100c43fe2e). Styles: tokens/css/ury-v16/components/pos-dialogs.css. Variants: see states.json.
