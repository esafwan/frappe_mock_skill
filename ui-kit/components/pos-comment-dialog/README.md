# pos-comment-dialog

Order comment dialog (CommentDialog.tsx wrapping packages/ui CommentDialog): message icon title, label, 128px textarea and Cancel / Save Comment buttons in a 448px dialog.

Shown from the cart when a server adds a note to the whole order.

Source: pos/src/components (URY v16 @100c43fe2e). Styles: tokens/css/ury-v16/components/pos-dialogs.css. Variants: see states.json.
