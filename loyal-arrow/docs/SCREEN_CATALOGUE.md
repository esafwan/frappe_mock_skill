# Loyal Arrow screen and component catalogue

Inventory for videos built on the kit system `loyal-arrow-desk` (on top of `frappe-desk`) plus `loyal-arrow-counter` (mobile counter PWA). Derived by opening every reference screenshot. All data shown is seeded synthetic. Reference images live under `/Users/safwan/Code/LoyalArrow/dumps/screenshots/` (called `$S` below). Copy into the repo only downscaled (max 1280 px wide) into `loyal-arrow/docs/refs/`, and only the synthetic ones listed here.

Shared shell (all desk screens, 1440x900): left icon rail (app logo tile, search, bell, assistant, gift app icon, avatar bottom), 224 px sidebar with workspace switcher "Loyal Arrow", sections Home, Members, Points & rewards, Campaigns, Insights, Arrow AI, Approvals, Program setup, Connections, System health, Internal records (one section expanded, active leaf has white pill), page head (title left; Actions menu, refresh, print, "..." and primary button on the right).

Legend for states: P populated, E empty, Z zero, L loading, X error, B background-report (generate first).
