# Feature catalogues

Plain-language lists of what each app actually does today. Source of truth for anyone building mocks, screens, storyboards, narration or proposals.

## Rule

1. Before building a mock or screen for an app, read its catalogue.
2. Only show features the catalogue lists as built. Respect "(off by default)" notes.
3. Never mock items under "Planned" as shipped, and never claim anything under "Gaps a writer should not claim".
4. If a feature is missing from the catalogue, ask before inventing it.
